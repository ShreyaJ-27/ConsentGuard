Consent Passport

Local prototype for reviewing and managing a scoped consent request.

Important security notice

Demo only — not identity verification. This prototype does not authenticate a subject or match a face. When demo subject actions are enabled, the partner receives a simulated bearer code. Do not use this flow or real API credentials in production.

Connect to the local gateway

The page sends this key only in the X-API-Key header to the configured gateway. It is not saved in local storage. Never enter a production partner key here.

Create a demo consent request

First obtain a server-issued check ID. This page can make a demo check or you can paste an existing eligible check ID. A consent request can only be created from a recorded, unexpired needs_consent check with a target reference.
